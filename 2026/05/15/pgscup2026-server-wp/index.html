PGSCUP 2026 | 服务器取证 WriteUp

2026/5/15 WriteUp PGSCUP 服务器取证 PVE Ceph MySQL

检材： 三节点 PVE 集群镜像 + VM100（金麟资本理财平台）
分析时间： 2026-05-10

本文为 PGSCUP 2026 服务器取证赛道完整解题记录，共 30 题。

Q1 — PVE 主机版本号

9.1.1

三节点都跑 pveversion，输出一致。

Q2 — PVE 主机内核版本

6.17.2-1-pve

uname -r 或者看 anaconda-ks.cfg。

Q3 — PVE 集群名

pgscup2026

/etc/corosync/corosync.conf 和 pvecm status 都有。

Q4 — 加入集群指纹前 6 位

20:76:ac

ssh-keygen -lE md5 -f /etc/ssh/ssh_host_ecdsa_key.pub
# 256 MD5:20:76:ac:89:e5:b9:9c:b0:61:29:ff:fc:2c:7d:c7:f3

Q5 — 时间服务器

ntp.aliyun.com

/etc/chrony/chrony.conf 和 timesyncd.conf 都指向阿里云。

Q6 — Ceph 资源池名

Ceph_pgscup_pool

看 /etc/pve/storage.cfg：

rbd: Ceph_pgscup_pool
    content rootdir,images
    pool Ceph_pgscup_pool

Q7 — Ceph 资源池类别

RBD

pvesm status 看 Type 列。

Q8 — Ceph 集群 ID 前 8 位

3f28d8bb

/etc/ceph/ceph.conf 里 fsid 的前 8 位。

Q9 — Ceph 最小副本数

2

/etc/ceph/ceph.conf：

osd_pool_default_min_size = 2
osd_pool_default_size = 3

Q10 — 虚拟机快照创建时间

2026-04-16-15:05:19

VM 100 配置里 snaptime: 1776323119，转 CST：

date -d @1776323119 '+%Y-%m-%d-%H:%M:%S'

Q11 — VM 服务器内核版本

3.10.0-957.el7.x86_64

VM 100 没启动，所以走 RBD 只读映射挂载 /boot 分区：

rbd map Ceph_pgscup_pool/vm-100-disk-0 --read-only
mount -o ro,norecovery /dev/rbd0p1 /mnt/vm100_boot
ls /mnt/vm100_boot/vmlinuz-*
# vmlinuz-3.10.0-957.el7.x86_64

Q12 — SSH 端口

22

/etc/ssh/sshd_config → Port 22，systemd socket 也写死 ListenStream=22。

Q13 — 网卡 IP

192.168.0.70

/etc/sysconfig/network-scripts/ifcfg-eth0：

IPADDR="192.168.0.70"
PREFIX="24"
GATEWAY="192.168.0.1"

Q14 — 金麟资本域名

jlzb.vip

/etc/nginx/conf.d/jinqin.conf：

server_name jlzb.vip;
root /var/www/html/public;

jinqin = 金麟拼音，jlzb = 金麟资本缩写。

Q15 — 加密工具名称

encrypt_tool.py

位置：/root/encrypt_tool.py
外层是 POSIX shell 自解压脚本，gzip 解压后是 Python 源码。
.viminfo 里有编辑记录。

Q16 — 加密工具备份密码

JDSJ2026@Backup

payload 里写死：

password = 'JDSJ2026@Backup'
openssl aes-256-cbc -salt -pass pass:JDSJ2026@Backup

Q17 — XOR 密钥

0x5A

XOR_KEY = 0x5A
ord(c) ^ (XOR_KEY + i) % 256

Q18 — MySQL root 密码

pgscup@o26

三处都能看到：encrypt_tool.py 里 mysqldump 命令、/tmp/backup_db.sh、/tmp/import_data.py。

Q19 — 聊天记录数据表名

user_chat

CREATE TABLE `user_chat` (
  `from_user_id`, `to_user_id`, `content`,
  `offline`, `type`, `add_time`
)

Model 文件 app/UserChat.php 也是 protected $table = 'user_chat'。

Q20 — type=0 密码盐值

ABCDEFG

app/Users.php：

if ($type == 0) {
    $salt = 'ABCDEFG';
    foreach (str_split($password) as $char) {
        $salt .= md5($char);
    }
}
return md5($salt);

验证：MakePassword('www9nwcc') 的结果和数据库里存的一致。

Q21 — Laravel APP_KEY 后 8 位

sJ2LPg28

/tmp/licai/.env：

APP_KEY=base64:puS70d5BEDqnBMNFa2WBtxRfFyEybPtVv/rsJ2LPg28=

去掉 base64: 前缀和 = padding，取末尾 8 位。

Q22 — 后台机器人数量

3

robot 表里面 (9,...),(10,...),(11,...) 三条。legal_robot 是另一个表，不算。

Q23 — 聊天记录总数

11494

jinqin_backup.sql 里 user_chat 表精确计数，id 从 1 到 11494 连续。

Q24 — 注册用户总数

21722

users 表，id 1~21722，连续无缺口。

Q25 — 季丽华身份证号

370100196901274436

在 user_real 表里：(21826,21702,'季丽华','370100196901274436',...)

Q26 — 钱包流水金额第二大用户

平玉珍

wallet_log 表按 user_id 汇总 change 绝对值：

用户 金额
马旭 29752.00
平玉珍 28856.00
吴俊 28594.00

Q27 — 法币交易最多卖家笔数

1727

legal_deal 表按 seller_id 分组：

seller_id=24  1727 笔
seller_id=37  1695 笔
seller_id=67  1695 笔

Q28 — 已完成结算杠杆交易保证金最多

37240.76

lever_transaction 表，取 status=3（已平仓），按 user_id 汇总 origin_caution_money：

贺伟 (10423)  37240.76
孙辉 (4650)   36901.28
陆鹏 (7396)   36506.18

settled 字段全为 0，这里用 status=3 对应「已完成结算」。

Q29 — 余额最小商家手机号

15860623709

seller 表 mobile 字段，余额最低的是 user_id=4。

Q30 — 余额最小商家余额

8461.4

同上：seller_balance = 8461.40000
